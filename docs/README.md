# Intercross

## Introduction

Intercross is an open-source Android app designed for plant breeders to track and manage crossing activities. It supports recording parental crosses, tracking progress toward breeding goals with wishlists, collecting metadata, and printing custom labels via Zebra mobile printers.

Developed as part of the PhenoApps initiative, Intercross modernizes data collection in plant breeding using mobile technology.

## Getting Started

Download Intercross from:
- [Google Play Store](https://play.google.com/store/apps/details?id=org.phenoapps.intercross)
- [GitHub Releases](https://github.com/PhenoApps/Intercross/releases)

When you first open Intercross, complete:
1. Initial setup and permissions
2. Storage location selection
3. Profile configuration (optional but recommended)

## Key Features

| Feature | Description |
|---------|-------------|
| Cross Recording | Enter parents via keyboard or barcode scanner |
| Wishlist Tracking | Set targets and monitor progress toward crossing goals |
| Cross Block Matrix | Visual grid of all parent combinations |
| Metadata Collection | Record seeds, fruits, flowers, and custom fields |
| Label Printing | Print barcoded labels via Zebra Bluetooth printers |
| Data Export | Export crosses as CSV files |
| Summary Charts | Visual analytics of crossing activity |
