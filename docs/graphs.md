# Summary

The Summary screen provides visual representations of your crossing data through interactive charts and statistics.

## Overview

The Summary dashboard displays:
- **Key Metrics** — Quick stats at the top (total crosses, types, active days)
- **Crosses Chart** — Bar chart showing cross type distribution
- **Metadata Chart** — Bar chart showing collected metadata (seeds, fruits, flowers)
- **Crosses Over Time** — Line chart showing crossing activity trends

## Key Metrics Cards

Three summary cards display at the top:
- **Crosses** — Total number of recorded crosses
- **Types** — Number of different cross types
- **Days** — Number of days with crossing activity
